01 · The mental model

Three jobs, three kinds of tool

Usenet sounds complicated because several small tools each own one step. The cleanest model is: find a pointer, fetch the pieces, organize the result.

1

Indexers find

NZBGeek and NZBFinder catalogue posts and produce an NZB: a small instruction file that points to article pieces on Usenet.

NZBGeek · NZBFinder · Prowlarr

2

The client fetches

SABnzbd reads the NZB, asks Eweka for the article pieces, checks them, repairs missing parts when possible, and unpacks the result.

Eweka · SABnzbd · PAR2

3

Automation organizes

Radarr, Sonarr, or the cart importer moves a verified completion into the canonical library. Plex discovers it there.

Radarr · Sonarr · cart importer · Plex

The NZB is not the media. It is closer to a shipping manifest: useful directions to many Usenet articles. Eweka supplies the articles; SAB assembles them.

04 · Daily use

Two ways to ask for something

Release-first

Use a cart

  1. Pick a specific release in NZBGeek My Cart or NZBFinder Cart.
  2. Allow up to 15 minutes for the feed to register it with SAB.
  3. Follow download, repair and unpack in SAB. A capacity hold may deliberately keep it from starting.
  4. The cart importer takes an eligible completion through native import, independent verification and exact scratch cleanup.
  5. Look in the appropriate Remote Plex library. Select a NAS copy separately only if wanted.

Best when you care about the exact release. Cart jobs are not automatically owned by Radarr or Sonarr.

Title-first

Use Radarr or Sonarr

  1. Add a movie in Radarr or a series in Sonarr. Choose monitoring and a quality profile deliberately.
  2. The Arr application searches the indexers through Prowlarr and sends a match to SAB.
  3. Follow acquisition in SAB and import in the Arr queue/history.
  4. Arr imports the completion into the canonical library and owns completed-client cleanup.
  5. Look in the corresponding Remote Plex library. A local NAS copy remains an explicit choice.

Best when you care about the title and quality policy more than a particular release.

05 · Storage boundaries

Canonical, temporary, local, backed up

C

Canonical library · Storage Box

The authoritative Movies and TV files live here. Cloud applications can write through the controlled import path. The NAS receives read-only access.

T

Temporary scratch · cloud disk

SAB downloads, repairs and unpacks here. It is working space, not a library and not a backup. Failed or retained jobs continue to consume capacity.

L

Local copy · NAS

An optional selected copy for local playback. Copying verifies the selected source and destination; it does not subscribe the NAS to future episodes or upgrades.

B

Backups · configuration and receipts

Encrypted scheduled archives cover configuration, databases, controller state and integrity receipts. They do not duplicate the whole media library or establish whole-NAS disaster recovery.

Storage Box snapshots are not independent backups. They share the same storage system and consume its capacity. Treat the canonical library and configuration backup scopes separately.

What is deployed—and what is still open

Deployed / observed

  • Private cloud search and download applications
  • Canonical Storage Box movie and TV library paths
  • Automatic cart importer with durable journals
  • Verified selective NAS movie copying and safe repeat
  • Separate Plex NAS and Remote libraries
  • Scheduled encrypted configuration backups

Still needs acceptance

  • Durable receipt and backup review for the latest cart imports
  • A fresh TV completion and selective NAS TV copy
  • Fresh Arr-owned movie and TV cleanup evidence
  • Sequential capacity admission under burst and unpack pressure
  • Apple TV and Roku playback, seeking and cold-start privacy

07 · When something stalls

Start with the owner of the stuck step

SymptomLook firstSafe response
Scratch is full or SAB reports “no space”SAB queue/history, cloud health, importer journals and filesystem usageKeep acquisition held. Do not delete failures, clear history, resume a large job or restart SAB until exact jobs and durable state are reconciled.
A job is pausedSAB’s per-job pause and current capacity notesAssume it may be a manual or protective pause. Do not release it just to make the queue move.
SAB, Prowlarr, Radarr or Sonarr is unavailablePrivate route first, then discovery/cloud healthSeparate network reachability from an application failure. Recheck after scratch recovery; do not assume every HTTP error has one cause.
Download finished but import is delayedArr queue/history for Arr jobs; cart importer status and journal phase for cart jobsPreserve the completion and journal. Never replay an import or reset activation blindly.
Imported item is not visible in PlexCorrect NAS versus Remote library and Plex scan timingWait for normal discovery or target only the selected directory if the runbook calls for it. Never expose private libraries or empty trash to force a result.
NAS copy failedNAS Downloads panel, free-space reserve, source availability and exact failure textRetry only the same owned item after the blocking condition is fixed. Do not overwrite an unrelated destination or grant the NAS write access upstream.

09 · Plain-English glossary

Terms you will actually see

Provider
A paid service, here Eweka, that serves Usenet articles to the download client.
Indexer
A searchable catalogue that turns a desired post into an NZB pointer file.
NZB
A small XML instruction file listing the Usenet article pieces needed for a job; it is not the downloaded payload.
Retention
How far back a provider keeps articles. Older availability can improve the odds of finding every piece.
Completion
Whether the provider has enough of the required article pieces to reconstruct the post.
PAR2 repair
Recovery data that can rebuild some missing or damaged pieces. Repair consumes temporary disk space.
Unpacking
Extracting the finished files from archives after verification or repair. Peak space may include both archives and extracted output.
RSS
A periodic feed check. The two carts are polled every 15 minutes; polling a request is not the same as admitting its payload to disk.
Quality profile
Radarr or Sonarr rules describing acceptable resolution, source, upgrades and cutoffs.
Canonical
The authoritative copy. In this system that is the Storage Box library, not cloud scratch or an optional NAS copy.
